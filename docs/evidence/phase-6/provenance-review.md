# Phase 6 Task 5 — provenance and originality review

Status: **Complete 2026-09-13.** Reviews candidate provenance only. Approves no candidate, promotes nothing, and scores nothing.
Machine-checked register: `docs/evidence/phase-6/provenance-register.json`
Guard: `packages/testing/src/phase6-provenance.unit.test.ts`

## What the brief requires

For every reference behind a candidate: source URL or file, creator where known, licence or usage basis, retrieval date, and the specific abstract quality referenced. Two things are forbidden outright — imitating a named living artist, and reproducing a commercial product's distinctive visual identity.

Nine references are recorded, each carrying all five fields, each naming the candidates it applies to. All three candidates share all nine, because all three are generated from one geometry module and differ only in treatment.

## The finding that matters

**No external visual reference was consulted at all.**

The brief expressly permits references that establish "general architectural, material, ergonomic, photographic, or historical qualities." Zero were used. Six of the nine references are the project's own approved documents, one is geometry authored in-tree, one is the WCAG 2.2 specification, and one pair is typeface families named in a CSS fallback stack. No image was traced, sampled, generated by a model, or copied. No external asset is fetched at build time — the only external URL anywhere in the candidate sources is the SVG XML namespace.

That is a clean originality result and a thin research result, and they are the same fact. These candidates cannot infringe anything because nothing outside the repository informed them; they also cannot claim to be grounded in how studios are actually built, lit, or occupied, because nobody looked. A reviewer scoring "material coherence and depth" at Task 7 is scoring invention, not observation.

This is recorded as an open gap rather than resolved, because resolving it is a scope decision only the owner can make. It does not block Tasks 2–4, whose acceptance is the twelve board deliverables against the frozen frame — all of which exist.

## Originality attestation

Neither forbidden thing occurred:

- **No named living artist was imitated.** No artist's work was sought, viewed, or used as a target. The three emphases — architectural clarity, human studio warmth, miniature craft precision — come from the owner's own brief, not from anyone's portfolio.
- **No commercial product's visual identity was reproduced.** No palette, icon set, layout signature, or avatar system was taken from any product. The isometric projection is standard trigonometry and carries no authorship claim.

## Typefaces: a deferred licence question, named rather than buried

Six typeface families are referenced by name across the two CSS stacks. **None is embedded, converted, or redistributed by this repository** — each resolves from the viewer's installed fonts, and both stacks end in a generic family, so no candidate depends on a proprietary face to read correctly. No font licence is exercised today.

Phase 7 is where that changes. The moment a candidate's type is embedded rather than system-resolved, a licence review is required. Of the six named faces, **Cascadia Mono (SIL Open Font License 1.1) is the only one that would survive that review unchanged.** Iowan Old Style, Palatino Linotype, Segoe UI, Consolas and SF Mono are proprietary and would each need separate clearance or replacement.

The register records this as a gap with a named trigger rather than as a resolved item, because it is genuinely unresolved — it is simply not yet due.

## Generated assets: the category this register cannot vouch for

Decision 6-C approved a hybrid medium. The generated half was not produced, and each manifest records `generatedExploration: null` rather than implying coverage.

Worth stating plainly while the decision is still open: generated raster is the one asset category whose provenance this register could not enumerate to the brief's standard. "Source URL or file, creator where known, licence basis" has no honest answer for a model output. That is not an argument against using it — the brief explicitly permits generated assets as Candidate — but it is a cost that should be weighed against what the generated half would actually add, which is material and mood plates only, since no image model can render six specific agents at declared work areas with one active work item.

## How this review is enforced

Eight machine checks over the register, not a prose sign-off:

| Check | What it prevents |
| --- | --- |
| All five required fields present and non-empty | An unsourced reference reaching a candidate |
| Creator named explicitly, including when unknown | "Where known" being read as licence to omit |
| Every in-tree source resolves to a real file | Citing a document that was renamed or never existed |
| Every candidate covered; no citation against an unknown candidate | A candidate shipping with no provenance at all |
| Manifest citations resolve to register references | A manifest inventing its own provenance |
| Both originality flags false, attestation substantive | A blank attestation passing as a clean result |
| Gaps non-empty, each with a finding and a disposition | "Nothing found" reading as "all clear" |
| Structured embedding metadata on every typeface | The font question being answered in prose that a guard greps |

Each was mutation-tested. Two notes on that:

- The last check originally matched the licence prose with a regular expression, and it **failed on phrasing rather than substance** — one entry said "is embedded … or redistributed," the other "not embedded or redistributed," and the guard could not tell the difference between those and a genuine claim. It was rewritten to read a structured field. A guard that greps prose passes on whatever wording it is handed.
- The first mutation run reported the "unsourced reference" guard as surviving. It had not survived: prettier had wrapped that string across two lines, so the mutation never applied and the run proved nothing. Re-run against the built register, the guard fails with the intended message. **A mutation that does not apply looks exactly like a guard that does not work** — which is the same shape as a green run that proves nothing, arriving in the tooling built to detect it.

## Disposition

Task 5 is complete. No candidate is blocked on provenance grounds. Three gaps are open and recorded: no external visual reference, the unexercised generated half, and typeface embedding deferred to Phase 7. None blocks Task 6 or Task 7; all three are the owner's to weigh at Task 8.
